# PiChan Vector Assets

**Logo Master:** v2.0  
**Status:** LOCKED

## Source hierarchy

`PiChan_Icon_Master.svg` is the one canonical PiChan bird geometry.

`PiChan_Wordmark_LightBG.svg` and `PiChan_Wordmark_DarkBG.svg` are the canonical approved wordmark vectors. Their design and color construction were not changed during the final bird refinement.

All other SVG files in this directory are approved derivatives of those masters.

## Final bird

The locked bird is the final **Curious PiChan / Concept B** refinement:

- observant, not angry
- curious and intelligent
- confident, not overly cute
- stronger body/wing balance
- organic silhouette rather than an egg-like outline
- full wing visible in circular/avatar applications

## Linked derivatives

To guarantee that repository derivatives always use the exact master geometry, some composite/utility SVGs reference the canonical SVG masters in this same directory rather than duplicating the bird geometry.

For standalone delivery, print, external design tools and archiving, use the self-contained files from the official production export package `PiChan_Brand_Master_FINAL_v2.0.zip`.

## Do not

- edit a derivative and treat it as a new master
- redraw the eye, beak, feathers, cheek dots or wing
- crop the wing in the circular badge
- change colors
- apply the official digital gradient to the core logo
- use legacy PiChan bird variants

Any future identity change requires a new logo-master version and synchronized changes to the brand documentation and implementation tokens.
