# PiChan Brand Source of Truth

**Status:** LOCKED  
**Version:** 1.0  
**Date:** September 2026

This folder contains the approved production identity for PiChan. Product UI, website, X assets, community assets and launch creative should reference these masters rather than recreating the logo from screenshots or older generated artwork.

## Master geometry

All logo variations use the exact same master PiChan bird geometry contained in `vector/PiChan_Icon_Master.svg`.

Do **not** redraw, reshape, rotate, add effects, change proportions, recolor arbitrarily, or use legacy bird variants.

## Logo hierarchy

1. **Primary:** horizontal PiChan bird + wordmark
2. **Secondary:** stacked bird + wordmark
3. **Avatar / app:** circular badge
4. **Small UI / favicon:** icon-only bird
5. **Monochrome:** master bird geometry in one color
6. **Wordmark-only:** custom PiChan lettering

## Core colors

- Deep Navy — `#041F5F`
- Cyan Blue — `#12B6F6`
- Royal Blue — `#153FE9`
- White — `#FFFFFF`

## Official digital gradient

Left → right, `0deg`:

`#153FE9 0%` → `#12B6F6 100%`

Use only for backgrounds, accents, selected UI surfaces and data visualization. Never use the gradient to recolor the PiChan bird master.

## Typography

- **Plus Jakarta Sans** — brand and product UI
- **JetBrains Mono** — numbers, wallet addresses, code and market data

## Minimum size

- Full horizontal logo: **120–140 px** minimum digital width; prefer 140 px when space allows
- Icon only: **24–32 px** minimum digital width
- Print: **40 mm** primary lockup / **8 mm** icon

## Messaging

- Primary tagline: **See what others miss.**
- Positioning: **Onchain intelligence & market discovery.**
- Personality line: **PiChan is watching.**
- Community: **PiChan | The Flock**

## Background usage

- Dark backgrounds: use the standard full-color master
- Light backgrounds: use the approved light-background/keyline variant
- Busy imagery: only use the logo where adequate contrast and clear space are preserved
