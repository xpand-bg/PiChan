# PiChan Brand Source of Truth

**Status:** LOCKED  
**Brand Guidelines:** v1.1  
**Logo Master:** v2.0  
**Date:** September 2026

This folder contains the approved production identity for PiChan. Product UI, website, X assets, community assets and launch creative must reference these masters rather than recreating the logo from screenshots or older generated artwork.

## Final identity decision

The final bird is the approved **Curious PiChan / Concept B** refinement.

It must read as:

- curious
- observant
- intelligent
- confident
- distinctive

It must **not** read as angry, childish, overly cute or generic.

The final silhouette is intentionally more organic than the earlier egg-like construction, with a stronger body/wing balance. In circular/avatar use the full wing remains visible and the bird keeps adequate breathing room.

Only the PiChan bird geometry changed in this final refinement. The approved wordmark construction and colors, palette, typography, gradient, messaging and other brand-system rules remain unchanged.

## Master geometry

All logo variations use the exact same master PiChan bird geometry contained in:

`vector/PiChan_Icon_Master.svg`

Do **not** redraw, reshape, rotate, add effects, change proportions, recolor arbitrarily, or use legacy bird variants.

## Logo hierarchy

1. **Primary:** horizontal PiChan bird + wordmark
2. **Secondary:** stacked bird + wordmark
3. **Avatar / app:** circular badge / app icon
4. **Small UI / favicon:** icon-only bird
5. **Monochrome:** exact master geometry in one color
6. **Wordmark-only:** approved custom PiChan lettering

## Official digital gradient

Left → right, `0deg`:

`#153FE9 0%` → `#12B6F6 100%`

Use only for backgrounds, accents, selected UI surfaces and data visualization. Never use the gradient to recolor the PiChan bird or wordmark.

## Typography

- **Plus Jakarta Sans** — brand and product UI
- **JetBrains Mono** — numbers, wallet addresses, code and market data

## Minimum size

- Full horizontal logo: **120–140 px** minimum digital width; prefer 140 px when space allows
- Icon only: **24–32 px** minimum digital width
- Print: **40 mm** primary lockup / **8 mm** icon

## Messaging — locked

- Primary tagline: **See what others miss.**
- Positioning: **Onchain intelligence & market discovery.**
- Personality line: **PiChan is watching.**
- Community: **PiChan | The Flock**

## Background usage

- Dark backgrounds: use the approved dark-background horizontal/stacked wordmark treatment
- Light backgrounds: use the approved light-background version; use the keyline icon variant where separation is needed
- Busy imagery: only use the logo where adequate contrast and clear space are preserved

## Clear space

For the full logo, preserve clear space on all sides equal to the height of the wordmark `i` dot. For the icon alone, use at least 12% of the icon width as clear space.

## Production rule

`PiChan_Icon_Master.svg` is the single bird source of truth. Every future icon, badge, social avatar, app icon, lockup and animation must derive from it without changing the geometry.
